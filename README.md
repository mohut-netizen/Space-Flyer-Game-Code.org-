# Space-Flyer-Game-Code.org-

This was a project I created in my high school introductory Computer Science course on 3/25/2023. This game was one of later projects and one of the projects done in Code.org that I am most proud of; many assets were edited manually to meet my aesthetic vision, and the code was written fully by hand - NO BLOCKS were used as I wanted to practice "real" coding. This class was my first exposure to programming, and was what fueled my passion for game development and eventually led me to study Computer Science and learn C# and Unity.

This project is a simple space game where you play as a spaceship battling gravity and obstacles. You must collect as many Stars as possible while staying within the bounds of the game. Avoid collecting Dark Stars and bumping into obstacles to stay in control of your spaceship to earn a high score!
